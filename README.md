## Deskripsi Project

Website portofolio ini dibuat untuk memenuhi tugas Pemrograman Web dengan menerapkan konsep **Responsive Web Design (RWD)**. Website terdiri dari 3 halaman utama yang terintegrasi dengan navigasi konsisten dan dapat diakses dengan baik di berbagai ukuran layar (desktop, tablet, dan mobile).

## Fitur Utama

### Halaman 1: Beranda (index.html)
- **Hero Section** dengan foto profil dan intro singkat
- **About Me Section** dengan deskripsi lengkap tentang background dan pengalaman
- **Skills Section** dengan progress bar visual untuk 5 keahlian utama:
  - HTML & CSS (60%)
  - JavaScript (50%)
  - C++ Programming (88%)
  - Python & Data Engineering (75%)
  - UI/UX Design (78%)
- **Footer** dengan link ke Institut Teknologi PLN
- Navigasi sticky yang tetap terlihat saat scroll

### Halaman 2: Portfolio (portfolio.html)
- **Tabel Responsif** yang menampilkan data proyek
- Informasi detail: No, Nama Project, Tahun, Teknologi, Status, Link Demo
- **7 data proyek** meliputi:
  - Website Portfolio (Bootstrap version)
  - Regresi Linear - Forecasting (Machine Learning)
  - Decision Tree - Klasifikasi (Machine Learning)
  - 4 project tambahan untuk dummy data
- Tabel dapat di-scroll horizontal pada layar mobile
- Hover effect pada baris tabel untuk UX yang lebih baik
- Link langsung ke GitHub repository dan live demo

### Halaman 3: Kontak (contact.html)
- **Form Request Project** yang lengkap dengan validasi
- **Text Input Fields:**
  - Nama Lengkap (required)
  - Email (required)
  - Nomor Telepon (optional)
- **Dropdown Select:** Jenis Layanan (Website, Landing Page, E-Commerce, Konsultasi, Lainnya)
- **Radio Buttons:** Estimasi Budget (1-3 juta, 3-5 juta, 5 juta+)
- **Textarea:** Deskripsi Proyek (required)
- **Checkbox:** Subscribe untuk update teknologi dan web development
- **Tombol Submit** untuk mengirim form

## Desain dan Style

- **Color Scheme:** 
  - Primary: `#334443` (Dark Gray-Green)
  - Accent: `#fab12f` (Golden Yellow)
  - Secondary: `#34656d` (Teal Blue)
  - Background: `#f9f5f0` (Light Cream)
- **Typography:** Arial, sans-serif
- **Layout:** Flexbox untuk struktur responsive
- **Effects:** Hover transitions, smooth scrolling, box shadows

## Teknologi yang Digunakan

- **HTML5** - Struktur semantic untuk semua halaman
- **CSS3** - Styling dan desain responsive
- **Flexbox** - Layout sistem yang flexible
- **Media Queries** - Responsive breakpoints:
  - Desktop: > 1024px
  - Tablet: 768px - 1024px
  - Mobile: < 768px
